# Get df_counting results

Wrapper for df_counting, safely executes and returns results for
survival analysis.

## Usage

``` r
get_dfcounting(...)
```

## Arguments

- ...:

  Arguments passed to
  [`df_counting`](https://larry-leon.github.io/weightedsurv/reference/df_counting.md).

## Value

Result from df_counting or NULL if error.
